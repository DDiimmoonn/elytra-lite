# ElytraSpeed plugin

Плагин для Purpur (Paper) 1.26.2 — улучшение/модификация скорости полёта с элитрами.

Уровни элитр (и соответствующие множители) задаются в config.yml (по умолчанию: -50%, -30%, -10%, +10%, +30%).

Установка:
1. Скомпилируйте (или скачайте JAR из релиза) и поместите JAR в папку plugins на сервере Purpur.
2. Перезапустите сервер.
3. Настройки в plugins/ElytraSpeed/config.yml

Команды:
- /gelytra <ник> <уровень> — выдать элитру с уровнем 1..5 (требует permission elytraspeed.give или OP).
